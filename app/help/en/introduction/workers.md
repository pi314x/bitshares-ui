# Workers

Workers are proposals to perform a service in return for a salary from the
blockchain. A worker proposal contains at a minimum the following information:

* A start and an end date
* A daily pay
* A maximum total pay
* A link to a webpage where the worker proposal is explained

## Voting for workers

You can vote for a worker proposal if you want it to be funded, or against it if
you think it should not be paid. The weight of your vote equals the number of BTS
you own. A proposal is paid only while it has more votes than the refund
threshold. See [Voting](/help/voting) for the lifecycle of a worker proposal.

## Budget

Workers are paid from a fixed daily budget, in order of their votes, until there
is no more money left. With a daily budget of 400k BTS and five proposals with
positive votes that each ask for 100k BTS a day, the four proposals with the most
votes receive 100k BTS each, and the fifth one receives nothing.
