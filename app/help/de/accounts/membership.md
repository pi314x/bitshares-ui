# Mitgliedschaften

Konten in BitShares werden in drei Gruppen eingeteilt. Wir geben Nutzern die
Möglichkeit, ihr Konto auf einen VIP-ähnlichen Status hochzustufen, wenn sie das
wünschen, und von geringeren Gebühren und zusätzlichen Funktionen zu profitieren.

## Nicht-Mitglieder

Ein *normales* Konto ist ein *Nicht-Mitglied*.

## Lifetime-Mitglieder

Lifetime-Mitglieder erhalten bei jeder gezahlten Transaktionsgebühr einen
prozentualen Cashback sowie Einnahmen aus Empfehlungen. Eine Lifetime-Mitgliedschaft
kostet einmalig eine Gebühr, die in dieser [Gebührenübersicht](/explorer/fees)
festgelegt ist.

### Gebührenaufteilung

Jedes Mal, wenn ein von dir empfohlenes Konto eine Transaktionsgebühr zahlt,
wird diese Gebühr auf mehrere Konten aufgeteilt. Das Netzwerk erhält einen Anteil,
und das Lifetime-Mitglied, das das Konto empfohlen hat, erhält einen Anteil.

Der Registrar ist das Konto, das die Transaktionsgebühr für die Registrierung des
Kontos im Netzwerk bezahlt hat. Der Registrar entscheidet, wie er die
verbleibende Gebühr zwischen sich und seinem eigenen Affiliate aufteilt.

### Ausstehende Gebühren

Gezahlte Gebühren werden nur einmal pro Wartungsintervall auf das Netzwerk, die
Referrer und die Registrare aufgeteilt.

### Vesting-Gebühren

Die meisten Gebühren stehen sofort zur Verfügung. Gebühren über dem Vesting-Schwellenwert
(etwa für das Upgrade deiner Mitgliedschaft oder die Registrierung eines
Premium-Kontonamens) müssen dagegen über einen vom Komitee festgelegten Zeitraum
freigegeben werden (Vesting).
