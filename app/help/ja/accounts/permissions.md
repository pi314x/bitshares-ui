# 権限

BitSharesでは、各アカウントは次のように分けられます。

* **アクティブ権限**: 資金の管理
* **オーナー権限**: アカウントの管理

どちらも、アカウントの`権限`タブで、*オーソリティ*(下記参照)と、取引が有効になるために超える必要がある*しきい値*を使って定義できます。

## オーソリティ

BitSharesでは、*オーソリティ*は、送金や取引などのアクションを承認する1つまたは複数の主体で構成されます。

オーソリティは、アカウント名と*重み*のペアを1組以上組み合わせたものです。

有効な取引にするには、署名する当事者の重みの合計が、権限で定められたしきい値を超える必要があります。

# 例

用語と使い方を理解しやすくするために、いくつか例を見てみましょう。新しいアカウントを作成し、そのアクティブ権限を以下のように設定したものとします。同じ方式がオーナー権限にも使えることに注意してください。

## (フラットな)マルチシグ

フラットなマルチシグ方式は、`M`個の主体のうち`N`個が署名したときに取引が有効になる仕組みです。BitSharesでは、`M`と`N`の代わりに*重み*と*しきい値*を使います。それでも、これから見るように、同じことをさらに柔軟に実現できます。

Alice、Bob、Charlie、Dennisが共同の資金を持っているとします。そのうち2人が同意すれば有効な取引を作れるようにしたいとします。**4人中2人**(N-of-M)の方式は、次のようになります。

| アカウント | 重み   |
| ---------- | ------ |
| Alice      | 33%    |
| Bob        | 33%    |
| Charlie    | 33%    |
| Dennis     | 33%    |
| ---------- | ------ |
| しきい値:  | 51%    |

4人全員の重みは33%ですが、しきい値は51%に設定されています。そのため、4人のうち2人が同意すれば取引が有効になります。

4人中3人の方式にするには、重みを17に下げるか、しきい値を99%に上げます。

## (フラットな)柔軟なマルチシグ

しきい値と重みを使うと、資金に対してより柔軟に、より正確には、より多くの*管理*を行えます。たとえば、人によって異なる重みを設定できます。Aliceがマルチシグで資金を盗難から守りたいが、友人に権限を渡しすぎたくないとします。その場合、次のようなオーソリティを作成します。

| アカウント | 重み   |
| ---------- | ------ |
| Alice      | 49%    |
| Bob        | 25%    |
| Charlie    | 25%    |
| Dennis     | 10%    |
| ---------- | ------ |
| しきい値:  | 51%    |

これで、資金にはAliceと友人1人、または友人3人全員が一緒にアクセスできます。

## 多階層の柔軟なマルチシグ

簡単な多階層の企業アカウントの設定を見てみましょう。最高財務責任者(CFO)と、その下で働く財務、経理、税務、会計などの部署がある会社を考えます。この会社には、支出の権限を持ちたいCEOもいます。そこで、資金に対するオーソリティを次のように構成します。

| アカウント  | 重み   |
| ----------- | ------ |
| CEO.COMPANY | 51%    |
| CFO.COMPANY | 51%    |
| ----------- | ------ |
| しきい値:   | 51%    |

CEO.COMPANYとCFO.COMPANYは、それぞれ独自のオーソリティを持っています。たとえば、CFO.COMPANYアカウントは次のようになります。

| CFO.COMPANY         | 重み   |
| ------------------- | ------ |
| Chief.COMPANY       | 51%    |
| Treasurer.COMPANY   | 33%    |
| Controller.COMPANY  | 33%    |
| Tax Manager.COMPANY | 10%    |
| Accounting.COMPANY  | 10%    |
| ------------------- | ------ |
| しきい値:           | 51%    |

この方式では、次のことができます。

* CEOが資金を使える
* 最高財務責任者が資金を使える
* TreasurerとControllerが一緒に資金を使える
* ControllerまたはTreasurerが、Tax ManagerおよびAccountingと一緒に資金を使える

このように、任意の深さのツリーを作ることで、ほぼあらゆるビジネスの用途に合わせた柔軟なオーソリティを構成できます。
