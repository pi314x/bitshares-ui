# 取引

このページでは、DEXで使われる用語の読み方と、取引ペアの表示方法について簡単に紹介します。

## ペア

BitSharesでは、ほとんどのアセットを他のすべてのアセットと取引できます。2つのアセットを選ぶと、通常は*マーケットペア*と呼ばれます。たとえば、USD:EURペアでUSDとEURを取引できます。

一貫性を保つため、一般的な用語である*base*と*quote*を使って、ペアを次のように表します。

    *quote* : *base*

たとえば、*base*がUSD、*quote*がEURの場合、EUR:USDペアになります。

## 板

板は、*ask*側と*bid*側で構成されます。取引ペアには優先される向きがなく、反転できるため、次の表で各側のask/bidと、それに対応する売買操作をまとめます。

| 側         | 売り    | 買い    |
| ---------- | ------- | ------- |
| Ask        | *quote* | *base*  |
| Bid        | *base*  | *quote* |
| ---------- | ------- | ------- |

当然ながら、USD:EURペアのbid側にあるものは、EUR:USDペアではask側にあります。価格は内部的には分数で表されるため、両方のペアは同一になります。

## 取引する

取引注文を出すには、*ask*側または*bid*側(それぞれ*買い*側または*売り*側)のフォームに入力する必要があります。売買する*価格*と*数量*を指定する必要があります。この注文のコストは自動的に計算されます。注文を出すには、別途手数料がかかります。

注文が約定すると(つまり、誰かがあなたのオファーを売買すると)、対応するアセットがあなたのアカウントに入金されます。

約定していない注文は、いつでもキャンセルできます。
