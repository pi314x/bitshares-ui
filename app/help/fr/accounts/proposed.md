# Transactions proposées

Avec la fonction de propositions, chacun peut soumettre à la blockchain une transaction avec l'action « Proposée ».
C'est une fonction avancée qui permet de suggérer des actions pour des comptes que vous ne contrôlez pas vous-même.

Un compte peut par exemple être une multisignature de plusieurs autres comptes. L'une des parties soumet une proposition
(par exemple le transfert d'un actif), et les autres comptes de la multisignature approuvent la proposition.
Quand le seuil est atteint, la proposition est exécutée.

Si une proposition a été soumise pour votre compte sans que vous l'attendiez, soyez très prudent.
Si vous ne connaissez pas le compte qui vous a proposé quelque chose, ignorez la proposition, même si le nom du compte vous semble familier.
En cas de doute, contactez toujours directement les tiers concernés, comme les gateways, les bridges ou d'autres comptes.

Une transaction proposée a une date d'expiration ; une fois celle-ci dépassée, la proposition disparaît d'elle-même.
