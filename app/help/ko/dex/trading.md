# 거래

이 페이지에서는 DEX에서 사용하는 용어를 해석하는 방법과 거래 쌍이 표시되는
방식을 아주 간단히 소개합니다.

## 거래 쌍

BitShares에서는 거의 모든 자산을 다른 모든 자산과 거래할 수 있습니다. 두 자산을
고르면 보통 *마켓 쌍*이라고 부릅니다. 예를 들어 USD:EUR 쌍에서 USD를 EUR과
거래할 수 있습니다.

일관성을 위해 일반화된 용어인 *base*와 *quote*를 사용하여 쌍을 다음과 같이
표현합니다.

    *quote* : *base*

예를 들어 *base*가 USD이고 *quote*가 EUR이면 EUR:USD 쌍을 나타냅니다.

## 호가창

호가창은 *매도(ask)*와 *매수(bid)* 쪽으로 구성됩니다. 거래 쌍에는 선호하는
방향이 없고 뒤집을 수도 있으므로, 다음 표에서 각 쪽의 ask/bid와 그에 해당하는
매수/매도 동작을 정리했습니다.

| 쪽         | 매도    | 매수    |
| ---------- | ------- | ------- |
| Ask        | *quote* | *base*  |
| Bid        | *base*  | *quote* |
| ---------- | ------- | ------- |

당연히 USD:EUR 쌍의 bid 쪽에 있는 것은 EUR:USD 쌍의 ask 쪽에 나타납니다. 물론
가격은 내부적으로 분수로 표현되므로 두 쌍은 동일하게 됩니다.

## 거래하기

거래 주문을 하려면 *ask* 또는 *bid* 쪽(각각 *매수* 또는 *매도* 쪽)의 양식을
작성해야 합니다. 매도/매수할 *가격*과 *수량*을 정해야 합니다. 이 주문의 비용은
자동으로 계산됩니다. 주문을 실제로 넣으려면 추가 수수료가 필요하다는 점에
유의하세요.

주문이 체결되면(즉, 누군가 내 제안을 사거나 팔면) 해당 자산이 계정에 입금됩니다.

체결되지 않은 주문은 언제든 취소할 수 있습니다.
