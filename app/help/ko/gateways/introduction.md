# BitShares 게이트웨이

게이트웨이와 브리지는 BitShares 블록체인에 기본으로 존재하지 않는 자산을
BitShares 블록체인으로 입금하고, 거래하고, 출금할 수 있게 해 주는 외부 서비스
제공업체입니다. 예를 들어 비트코인 블록체인의 BTC를 게이트웨이로 보내면,
게이트웨이는 BitShares 블록체인의 UIA(사용자 발행 자산)를 주고 나중에
(물론 수수료를 내고) 다시 출금할 수 있다고 약속합니다. BitShares 블록체인에서
이러한 UIA를 보유하고 있는 동안에는 게이트웨이가 자금의 수탁자가 됩니다.
외부 서비스 제공업체의 서비스나 자산을 사용하면 해당 업체의 이용 약관에
암묵적으로 동의하게 됩니다.
