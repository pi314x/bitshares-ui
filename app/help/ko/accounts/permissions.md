# 사용권한

BitShares에서 각 계정은 다음과 같이 나뉩니다.

* **활성 사용권한**: 자금에 대한 통제권
* **소유자 사용권한**: 계정에 대한 통제권

두 권한 모두 계정의 `사용권한` 탭에서 *권한자*(아래 참고)와 트랜잭션이
유효하려면 넘어야 하는 *임계값*을 이용해 정의할 수 있습니다.

## 권한자

BitShares에서 *권한자*는 이체나 거래 같은 동작을 승인하는 하나 이상의 주체로
이루어집니다.

권한자는 계정 이름과 *가중치*의 쌍이 하나 이상 모인 것입니다.

트랜잭션이 유효하려면, 서명하는 당사자들의 가중치 합이 사용권한에 정의된
임계값을 넘어야 합니다.

# 예시

몇 가지 예시로 사용되는 용어와 활용 사례를 살펴보겠습니다. 새 계정을 만들고
활성 사용권한을 아래와 같이 설정했다고 가정합니다. 같은 방식이 소유자
사용권한에도 적용된다는 점에 유의하세요!

## (단층) 다중 서명

단층 다중 서명 방식은 `M`개의 주체 중 `N`개가 서명해야 트랜잭션이 유효한
구조입니다. BitShares에서는 `M`과 `N` 대신 *가중치*와 *임계값*을 사용합니다.
그래도 같은 것을 훨씬 유연하게 구현할 수 있다는 점을 곧 알게 됩니다.

Alice, Bob, Charlie, Dennis가 공동 자금을 가지고 있다고 가정합니다. 이 중 두
명만 동의해도 유효한 트랜잭션을 만들 수 있게 하려면 **4명 중 2명**(N-of-M)
방식은 다음과 같습니다.

| 계정       | 가중치 |
| ---------- | ------ |
| Alice      | 33%    |
| Bob        | 33%    |
| Charlie    | 33%    |
| Dennis     | 33%    |
| ---------- | ------ |
| 임계값:    | 51%    |

네 명 모두 가중치는 33%이지만 임계값은 51%로 설정됩니다. 따라서 네 명 중 두
명만 동의해도 트랜잭션이 유효해집니다.

4명 중 3명 방식을 만들려면 가중치를 17로 낮추거나 임계값을 99%로 높이면 됩니다.

## (단층) 유연한 다중 서명

임계값과 가중치를 사용하면 자금에 대한 유연성, 더 정확히는 더 많은 *통제권*을
가질 수 있습니다. 예를 들어 사람마다 다른 가중치를 줄 수 있습니다. Alice가
다중 서명으로 자금을 도난으로부터 지키되 친구들에게 너무 많은 통제권을 주고
싶지 않다고 가정해 봅시다. 그러면 다음과 비슷한 권한자를 만듭니다.

| 계정       | 가중치 |
| ---------- | ------ |
| Alice      | 49%    |
| Bob        | 25%    |
| Charlie    | 25%    |
| Dennis     | 10%    |
| ---------- | ------ |
| 임계값:    | 51%    |

이제 자금은 Alice와 친구 한 명이 함께하거나, 친구 세 명이 모두 함께해야 사용할 수 있습니다.

## 다단계 계층형 유연한 다중 서명

간단한 다단계 계층형 기업 계정 구성을 살펴보겠습니다. 최고재무책임자(CFO)와
그 밑에서 일하는 재무, 관리, 세무, 회계 등의 부서가 있는 회사를 생각해
보세요. 이 회사에는 지출 권한을 갖고 싶어 하는 CEO도 있습니다. 그래서 자금에
대한 권한자를 다음과 같이 구성합니다.

| 계정        | 가중치 |
| ----------- | ------ |
| CEO.COMPANY | 51%    |
| CFO.COMPANY | 51%    |
| ----------- | ------ |
| 임계값:     | 51%    |

여기서 CEO.COMPANY와 CFO.COMPANY는 각자의 권한자를 가집니다. 예를 들어
CFO.COMPANY 계정은 다음과 같을 수 있습니다.

| CFO.COMPANY         | 가중치 |
| ------------------- | ------ |
| Chief.COMPANY       | 51%    |
| Treasurer.COMPANY   | 33%    |
| Controller.COMPANY  | 33%    |
| Tax Manager.COMPANY | 10%    |
| Accounting.COMPANY  | 10%    |
| ------------------- | ------ |
| 임계값:             | 51%    |

이 구성에서는 다음이 가능합니다.

* CEO가 자금을 사용
* 최고재무책임자가 자금을 사용
* Treasurer와 Controller가 함께 자금을 사용
* Controller 또는 Treasurer가 Tax Manager 및 Accounting과 함께 자금을 사용

따라서 임의 깊이의 트리를 구성하여 거의 모든 비즈니스 사례를 반영하는 유연한
권한자를 만들 수 있습니다.
