# Servicio de gateway Xbtsx

Xbtsx es un servicio de gateway construido sobre el exchange Bitshares. Un servicio de gateway se encarga de mover criptomonedas desde y hacia el exchange Bitshares. Admite una amplia gama de activos populares. Los activos admitidos por XbtsX se identifican fácilmente porque llevan el prefijo XBTSX.*. Por ejemplo, XBTSX.STH, XBTSX.POST, etc.
